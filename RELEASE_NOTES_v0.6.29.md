# Twitch Favorites Sidebar v0.6.29

18 octobre 2026 / October 18, 2026. Changes since v0.6.28.

## Français

- Historique du chat : conservation des mentions, du texte et des émoticônes répartis dans plusieurs éléments du message.
- Les badges chargés après le message sont désormais actualisés dans l’historique, sans doublon ni perte du contenu.
- Les badges déjà enregistrés sont conservés lorsque Twitch retire ou reconstruit le message.

## English

- Chat history preserves mentions, text and emotes spread across multiple message elements.
- Badges loaded after a message now update in history without duplicating the message or losing its content.
- Previously captured badges remain available when Twitch removes or rebuilds the message.

## Distributions

Chrome and Firefox ZIP packages; Android companion development APK (assembleDebug). These fixes affect the browser extension.
